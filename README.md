# OMerci-public

Public pages for the Oh Merci apps, served with GitHub Pages.

| Page | URL |
| --- | --- |
| Privacy Policy (client app) | https://massilpro316.github.io/OMerci-public/privacy-policy.html |
| Delete account (client app) | https://massilpro316.github.io/OMerci-public/delete-account.html |

Both pages are in French and English (FR/EN switch in the header, or add `?lang=en` / `?lang=fr` to the URL).

Use these URLs in Google Play Console:
- **App content → Privacy policy** → `privacy-policy.html`
- **App content → Data safety → Delete account URL** → `delete-account.html`
